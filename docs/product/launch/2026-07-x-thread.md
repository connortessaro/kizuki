1/ Launching kizuki today.

One command gives your AI agent a working understanding of your job:

claude mcp add kizuki -- npx -y kizuki mcp

Local-first, Apache-2.0.

2/ The problem: capable agents, blank context. Every session starts with you re-explaining who's blocked, what slipped, what was decided.

kizuki keeps a markdown vault of your work — meetings, GitHub, Jira, Outlook — and analyzes what each person and project needs.

3/ Rules it never breaks:

- observes and advises, never sends or acts
- deterministic code writes files, the model never edits them
- everything stays on your machine
- plain markdown, no lock-in

Works with Claude Code, Cursor, and Codex.

4/ Free to run locally, forever. A small paid founding cohort exists if you want it run for you.
