# Product

Positioning, roadmap, pricing and launch material for Kizuki as a product,
separated from the engineering docs one level up.

This is kept in the open on purpose. The repository is a record of building
something end to end, and deciding what to charge, who to sell it to, and what
not to build is part of that. It is not a claim that any of it shipped: there are
no customers, no waitlist to join, and the pricing here was never charged.

| Area | Files |
|---|---|
| Positioning | `product-readme.md`, `PRODUCT.md`, `MANIFESTO.md`, `vision.md` |
| Planning | `ROADMAP.md`, `BACKLOG.md`, `future-notes.md` |
| Ideation | `2026-07-07-jarvis-presence-ideation.md`, `2026-07-14-kizuki-direction-notes.md` |
| Go-to-market | `concierge/`, `launch/`, `org-tier/` |

Two things a reader will notice, both real:

**The licence position reversed twice.** Open-core, then closed-source on
2026-07-16, then back to Apache-2.0 on 2026-08-17. The documents carry
`Superseded` / `Un-superseded` banners rather than being rewritten, so the
reversal is legible instead of hidden.

**The roadmap is stale.** It describes a v1→v4 gate ladder from July 2026 and
predates the data plane entirely. It is left as written rather than
retrofitted — a roadmap edited to match what happened is not a roadmap.
